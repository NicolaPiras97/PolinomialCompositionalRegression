# Polinomial Regression model for Compositional Data.

This is the code we used for the simulation study in the paper "Polynomial compositional regression on the simplexa". 
The code in this version is available for case study reproducibility purposes only. 

## Usage

To run the simulations launch the .R files, which recalls the Functions_simplex.R file.
